## Currently

Working on **Project Spearhead** — one small model (≤3.5 M parameters) that does brain-tumour
segmentation and tumour-type classification in a single network, with an honest case-level
evaluation protocol instead of the pooled, leakage-prone scoring that is common in this literature.
Private for now; it becomes public once the evaluation harness is finished.

The thing I care about most there is not the score. It is that the number is reproducible.
